ReadMe

The Program file consist of the Details.java, Student.java, StudentManagementSystem.java and data.csv file

The Pseudocode files are not in this folder they are in a file labelled as "Pseudocode".
To run the program:
Step 1: Open the terminal in folder "Program"
Step 2 : Compile the java files
	javac *.java
Step 3: Execute the file
	java StudentManagementSystem
Step 4: Then the program can be used

Under the add student module, for the firstname the input accepts integers and I could not make it to accept only strings. This goes the same for any other variables declared as Strings.

Under the Edit student module, the student ID is typed in and matched with StudentIDs in the file. If found then it will let you to edit. I have only allowed editing to be done for courseEnrolled, yearLevel, cwa, Credits and Status. As we don't usually want to edit personal information as firstname, lastname, StudentId and citizenship.

Under viewStudent module, I have combined view all students, filter by course, filter by status and filter by citizenship( my own addition).

Highest CWA, display the highest CWA among all the students.

Average CWA, asks the user to input a Course of which the user wants to find the average CWA of. and it calculates the average and displays it.

Credits analysis, checks every students credits. if it is above 400 then they are allowed to graduate otherwise they can't.
Note: To run in Ubuntu, if the video doesn't work/play on your device, open it with Firefox or relevant browser.
